# SEMS – Simple Student Education Management System

SEMS është një aplikacion i thjeshtë për menaxhimin e materialeve mësimore dhe njoftimeve të provimeve.

## Teknologjitë

- React me Vite
- JavaScript
- CSS
- Supabase
- Solidity dhe Hardhat
- MetaMask dhe ethers.js
- Git dhe GitHub

## Struktura

- `frontend/` – aplikacioni React
- `smart-contracts/` – kontrata Solidity dhe projektet Hardhat
- `database/` – skedarët SQL dhe politikat e Supabase
